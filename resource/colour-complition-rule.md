### Rule for indicating which modifier keys are associated with the effect key

| Where color appears     | Meaning                                     |
| ----------------------- | ------------------------------------------- |
| Modifier key pie-circle | This modifier belongs to that color         |
| Effect/key label color  | Press all modifiers that contain this color |

### Example

| Effect label | Modifier pies containing same color | Press              |
| ------------ | ----------------------------------- | ------------------ |
| Red `del`    | Caps has red                        | Caps + Backspace   |
| Yellow `—`   | Caps has yellow + Shift has yellow  | Caps + Shift + `-` |
| Green `type` | Caps has green                      | Caps + B           |

### Modifier setup

| Modifier key | Pie colors           |
| ------------ | -------------------- |
| Caps         | Red + Yellow + Green |
| Shift        | Yellow               |
| Alt          | Blue                 |

This removes separate “dot meanings”.
The color itself becomes the binding rule.
